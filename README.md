# MoonFix — Lunar Mission Window Navigator

Interactive educational prototype for the 2026 NASA Space Apps Lunar Landing Site Navigator challenge.

**Run**: Open `index.html`. The app works offline and requires no login, API key or server. For a public URL, enable GitHub Pages with the `main` branch as the site source.

**Official demo (7 slides)**: `MoonFix_Demo_7_Slides.pdf`. **Optional 28-second video**: `MoonFix_Demo_28s.mp4`. These are individual links separate from the application's root URL.

**Sources / AI / limitations**: see `DATA_PROVENANCE_AND_AI.md`. The input values are a participant-supplied 720-sample reference table reported as NASA/JPL Horizons and LRO/LOLA derived; original raw processing has not been reproduced in this release. No NASA affiliation or mission certification is claimed.
